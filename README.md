# RepHavoc website

Static landing, support, and privacy pages for RepHavoc. Published by GitHub Pages from `main` at the repository root.

Intended domain: `rephavoc.granell.dev`.

DNS: create a CNAME record for `rephavoc` pointing to `antoniobg.github.io` (DNS-only if your provider offers proxying). GitHub Pages can then provision HTTPS for the custom domain.

No build step, analytics scripts, cookies, or external fonts. Barlow Condensed is bundled under the SIL Open Font License.
